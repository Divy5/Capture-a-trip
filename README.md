# Capture A Trip — Homepage

A modern and fully responsive travel website homepage developed as a frontend development assignment for Capture A Trip.

The project is built with Next.js and focuses on accurate UI implementation, responsive design, reusable components, performance, SEO, and a clean component-based architecture.

## 🚀 Live Demo

capture-a-trip.netlify.app

## 🛠️ Tech Stack

* Next.js
* JavaScript
* HTML5
* CSS3
* Tailwind CSS
* Next.js App Router
* Cloudinary
* JSON-LD / Structured Data

## 🧩 Project Architecture

The project follows a modular component-based architecture.

```text
app/
├── layout.js
├── page.js
└── globals.css

components/
├── destinations/
├── footer/
├── hero/
├── trip-analyzer/
└── upcoming-trips/

data/
├── destinations.js
├── footer.js
├── hero.js
├── tripAnalyzer.js
├── trips.js
└── upcomingTrips.js

public/
└── fonts/
```

Feature-specific components are separated into dedicated folders to improve maintainability, reusability, and scalability.

## ⚙️ Getting Started

### Clone the repository

```bash
git clone YOUR_REPOSITORY_URL
```

### Navigate to the project

```bash
cd capture-a-trip
```

### Install dependencies

```bash
npm install
```

### Run the development server

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```

## 🏗️ Production Build

Create a production build:

```bash
npm run build
```

Run the production server:

```bash
npm start
```
